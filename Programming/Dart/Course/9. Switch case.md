В Dart конструкция `switch case` имеет следующий синтаксис:
```
double studentScore = 4.9;

switch (studentScore) {
  case (> 4.5):
    print("You have been accepted with a grand");
    break;
  case > 3.5:
    print("You have been accepted without a grand");
    break;
  case <= 3.5:
    print("You haven't been accepted");
	break;
  default:
    print("We don't get the valid score");
}
```
