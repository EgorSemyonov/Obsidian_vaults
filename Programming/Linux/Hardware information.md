
Sometimes we need display some information about hardware or Operating System (farther OS). There a lot of approches how we can do that, but here I've desided to write down only native and simpiest commands.

**Information about:**
- OS
```bash
uname -a
```
- Processor
```bash
lscpu
```
- Memory (RAM):
```bash
free -h
```
- Disk
```bash
fdisk
```
