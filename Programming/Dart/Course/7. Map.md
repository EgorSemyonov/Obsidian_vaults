
## Основа Map (словарей)
`Map` - объект (словарь) содержащий в себе поля вида "ключ: значение" (аналог объекта в JavaScript)
```
Map student = {
	"name": "Egor", 
	"age": 24, 
	"lovesProgramming": true
};
print(student);
```

Чтобы конкретно прописать какие типы данных используются у свойств и их значений, мы по аналогии с [списками](6. List and set) можем задать типы перед объявлением самого объекта с помощью `<>`
```
Map student = <String, dynamic>{
  "name": "Egor",
  "age": 24,
  "lovesProgramming": true,
};
print(student);
```

Для обращения к полю объекта `Map` используется нотация через квадратные скобки
```
Map student = <String, dynamic>{
  "name": "Egor",
  "age": 24,
  "lovesProgramming": true,
};
print(student["name"]); // Egor
```
 *Добавление и переопределение полей, также происходит с помощью квадратных скобок*


## Методы Map (словарей)

- `addAll()`:
У словарей, в отличие от [списков](6. List and set) нет метода `add()`, но есть метод `addAll()`, принимающий в себя в качестве параметра, тот словарь, который мы хотим добавить
```
Map student = <String, dynamic>{
  "name": "Egor",
  "age": 24,
  "lovesProgramming": true,
};

student.addAll(<String, dynamic>{"job": "DevOps enginer", "salary": 2000});

print(
  student,
); // {name: Egor, age: 24, lovesProgramming: true, job: DevOps enginer, salary: 2000}
```
**Важно:** для объединения словарей, они должны иметь одинаковые типы свойств и значений

- `containsKey()` - проверяет наличие ключа
- `containsValue()` - проверяет наличие значения
```
Map student = <String, dynamic>{
  "name": "Egor",
  "age": 24,
  "lovesProgramming": true,
};

print(student.containsKey("lovesProgramming")); // true
print(student.containsValue(24)); // true
```
## Полезные свойства Map (словарей):

- keys - выводит `iterable` (итерируемый объект) с набором свойств словаря
- values - выводит `iterable` (итерируемый объект) с набором значений свойств словаря
- length - выводит длину словаря (кол-во записей вида "ключ: значение")
```
Map student = <String, dynamic>{
  "name": "Egor",
  "age": 24,
  "lovesProgramming": true,
};

print(student.keys); // (name, age, lovesProgramming)
print(student.values); // (Egor, 24, true)
print(student.length); // 3
```
