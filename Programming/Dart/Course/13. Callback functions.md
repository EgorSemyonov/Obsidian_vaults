
На самом деле любая функция в Dart является экземпляром такой сущности как класс `Function`
Для того чтобы создать функция на основании данного класса, достаточно использовать стандартный синтаксис создания переменной:
```
Function summarize = (int a, int b) {
  return a + b;
};
print(summarize(40, 2)); // 42
```
Грубо говоря в данном примере, мы создаем переменную с типом `Function` и присваиваем ей значение функции. Такая функция называется анонимной, т.к. вызывается не по имени функции, а по имени переменной в которой лежит ее логика выполнения (грубо говоря у данной функции нет имени, поэтому она "анонимная")

Также как и в JavaScript мы можем сократить анонимную функцию до синтаксиса стрелочной функции (синтаксический сахар):
```
Function summarize = (int a, int b) => a + b;

print(summarize(40, 2)); // 42
```

Также в Dart существуют `callback-функции`. Грубо говоря, `callback-функция` - это функция, которую мы передаем как параметр, внутрь другой основной функции, и вызываем, но не в момент передачи в качестве параметра, а внутри основной функции в тот момент, когда нам это необходимо.
