
Цикл `while` отрабатывает блок кода, до тех пор, пока условие является истинным. Синтаксис цикла в Dart:
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];

while (students.isNotEmpty) {
  print(students);
  students.removeLast();
}
```

Цикл `do while` мы используем когда важно проверить условие после выполнения действия (редко используется в production программировании)
```
int num = 10;

do {
  num += 15;
  print(num);
} while (num < 5);
```
