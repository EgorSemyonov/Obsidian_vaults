## Project structure:  

### Basics:

**Основные функции:**
- `main()` - точка входа в приложение, а именно, функция запускаемая операционной системой, при запуске приложения
- `runApp(const CaloriesUnderControl())` - инициализация Flutter с корневым виджетом, который мы передаем в функцию в качестве параметра
- `CaloriesUnderControl` - кастомный корневой класс, наследник StatelessWidget из Flutter библиотеки

Flutter под капотом, тем или иным образом, использует ID своих дочерних виджетов для перестроения интерфейса, поэтому при объявлении класса мы передаем его родителю так называемый `key` (id виджета) с помощью записи:

```
const CaloriesUnderControl({super.key});
```

`Scaffold` - это шаблон для **ОДНОЙ** страницы. Каждая страница будет иметь свой Scaffold   [Документация](https://api.flutter.dev/flutter/material/Scaffold-class.html)

`MaterialApp()` - это виджет, который настраивает приложение согласно правилам `Material Design` (дизайн система от Google). Он предоставляет:
- навигацию между экранами
- темы оформления
- локализацию
- другое

`BuildContext` - это контекст сборки, который содержит информацию о положении виджета в дереве. Виджет - это класс. Метод build внутри него - это функция которая возвращает дерево виджетов. `BuildContext` нужен для доступа к данным темы, навигации, и другим сервисам Flutter


## Useful widgets

1. **`HomeScreen`** - отдельный виджет для главного экрана
2. **`Column`** - вертикальное расположение виджетов
3. **`ElevatedButton`** - кнопка с возвышенным эффектом
4. **`SizedBox`** - невидимый виджет для создания отступов
5. **`Text('Some text', style: TextStyle(...)`** - стилизация текста
6. **`Container`** - универсальный виджет для управления позиционированием дочерних виджетов
7. **`ElevatedButton`** - кнопка с эффектом парения


## Code organization

Для выноса участков кода в отдельные файлы, достаточно создать в директории `lib` необходимые файлы или дочернюю директорию с такими файлами, а затем наполнить созданные файлы содержимым, которое необходимо вынести в отдельный блок. Теперь для доступа к вынесенным в отдельные файлы участкам кода, достаточно импортировать данный файлы в главном файле с помощью:

```dart
import 'package:flutter/material.dart';  
import 'screens/profile_screen.dart';  
import 'screens/calendar_screen.dart';  
import 'screens/home_screen.dart';  
import 'screens/goal_screen.dart';  
import 'screens/settings_screen.dart';
```

Теперь даже нет необходимости в aliase-ах, т.к. вы можете использовать в главном файле те же самые имена, которые используются в вынесенных в отдельные файлы участках кода.


## Statefull and Stateless widgets

Главное правильно, позволяющее определить какой тип виджета необходимо выбрать:

***<mark style="background: #D2B3FFA6; font-weight: 700; color: white">Состояние принадлежит тому, кто его меняет</mark>

Это означает, например, если поля с данными (управляют данным) находятся в модальном окне (не управляет данным), то поля с данными являются Statefull виджетом, а само модальное окно нет.
