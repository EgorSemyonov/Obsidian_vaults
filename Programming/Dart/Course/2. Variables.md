Переменные в dart создаются с помощью ключевого слова `var`
```
void main() {
  var title = "Some text from the variable";
  print(title);
}
```
Переназначение переменной:
```
void main() {
  var title = "Some text from the variable";
  title = "Another text from the variable";

  print(title);
}
```

С помощью ключевого слова `var` мы можем создавать переменные и автоматически присваивать им тип данных, исходя из значения переменной. Чтобы строго типизировать переменную, мы можем задать её не через `var`, а через указание типа данных вместо ключевого слова
```
void main() {
  String title = "Some text from the variable";
  int integerNumber = 777;
  double floatNumber = 777.7;
  bool booleanType = true;
  
  print(title);
  print(integerNumber);
  print(floatNumber);
  print(booleanType);
}
```
