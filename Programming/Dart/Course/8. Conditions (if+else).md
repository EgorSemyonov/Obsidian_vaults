Синтаксис условных конструкций в Dart очень сильно похож на условные конструкции JavaScript
```
List students = <String>['Egor', 'Liza', 'Anna']; 

if (students.contains('Egor')) {
  print('Egor is in the list of students');
} else {
  print('There isn\'t Egor in the list of students');
}
```
Чтобы добавить дополнительный блок проверки, помимо стандартных `if` и `else` необходимо использовать ключевые слова `else if`
```
List students = <String>['Egor', 'Liza', 'Anna'];

if (students.contains('Egor')) {
  print('Egor is in the list of students');
} else if (students.contains('Egorchik')) {
  print('Egorchik is in the list of students');
} else {
  print('There isn\'t Egor in the list of students');
}
```

Для того чтобы проверить соблюдение сразу нескольких условий в рамках одного блока `if / else if` необходимо использовать оператор логическое "и" - `&&`
```
int temperature = 25;

if (temperature > 10 && temperature < 30) {
  print("Go for a walk");
} else {
  print("Don't go for a walk");
}
```
Оператор логические "или" - `||` также следует применять в условных конструкциях. Условный блок отработает в случае, если хотя бы одно из выражений объеденных оператором `||` вернет true
