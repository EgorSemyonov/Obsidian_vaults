# Obsidian vaults  
  
### This repository has been made to join lots of my notes into one place.  
  
**Structure:**  
- Directories in the root are vaults  
- Their children are logical topics in a appropriate vault  
- Children of children are logical parts of main course (for instance: *ilm-policies* for *ElasticSearch* topic)  
- Every child has directory *images*, that are being used only by the articles in the same parent directory  
  
Let's learn it!
