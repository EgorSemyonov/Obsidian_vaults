
Синтаксис циклов в Dart:
- `for`
```
for (int i = 0; i < 5; i++) {
  print('Hello ${i}');
}
```
- `for in` - итерации по элементам итерируемых объектов без использования индексов
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];
for (String student in students) {
  print('Hello ${student}');
}
```
**Важно:** *используя цикл `for in` нельзя модернизировать элементы массива. Для таких задач лучше использовать цикл `for`*
