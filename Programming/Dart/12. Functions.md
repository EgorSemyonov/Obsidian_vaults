
Ключевое слово `void` из стандартного блока, с которым мы познакомились ранее, определяет то, что функция ничего не возвращает
```
void main() {
  ...
}
```

Синтаксис создания функции очень похож на синтаксис JavaScript. Важным отличием является необходимость в указании типа данных для параметров передаваемых в функцию
```
void square(int number) {
  print(number * number);
}

square(7); // 49
square(8); // 64
square(9); // 81
```

Для объявления функции, которая возвращает какое-либо значение, мы используем ту же логику что и с объявлением переменных, а именно, вместо слова `void` указываем тот тип данных, который будет возвращать функция
```
int square(int number) {
  return number *= number;
}

var result = square(7); // 49
print(result); // 49
```
