
Над переменными можно производить математические вычисления аналогично JavaScript
```
void main() {
  int number = 100;
  number = number + 1; // 101
  number += 1; // 102
  number++; // 103
}
```

Так же работает для вычитания и умножения:
```
void main() {
  int number = 100;
  number = number + 1; // 101
  number += 1; // 102
  number++; // 103

  number -= 3; //100
  number *= 10; //1000
}
```

Однако, для деления, необходимо выполнить дополнительный функционал, т.к. результатом деления всегда является тип данных `double`, т.е. число с плавающей запятой. Следовательно мы не можем переменную определенную изначально как `int` перезаписать с типом данных `double`. Для решения данной проблемы можно использовать преобразование типов данных с помощью встроенных функций:
```
void main() {
  int number = 100;
  number = (number / 10).toInt();
  print(number); // 10
}
```
*Операцию приведения типа данных к int можно записать лаконичнее:*
```
void main() {
  int number = 100;
  number = number ~/ 10;
  print(number); // 10
}
```

Также существуют операции поиска остатка от деления и поиска количества целочисленного вхождения числа при делении:
```
void main() {
  double doubleNumber = 4.5;
  print(doubleNumber % 2); // 0.5
  print(doubleNumber ~/ 4); // 1
}
```
Как мы видим из примера, оператор `~/` не преобразует тип данных, а показывает количество целочисленных вхождений числа при делении, что по сути своей не должно являться числом с плавающей запятой, поэтому и возвращает тип данных `int`

Операторы сравнения:
- == - проверяет равенство
- != - проверяет неравенство
- <, >, <=, >= - операторы сравнения
