
В языке dart помимо стандартных переменных есть также и константы. Они задаются с помощью ключевых слов `const` и `final`
```
void main() {
  const pi = 3.141592;
  final date = DateTime.now();

  print(pi); // 3.141592
  print(date); // 2025-07-26 16:48:25.403453
}
```

Ключевое отличие `const` от `final` в том, что переменная заданная с помощью `const` получает свое значение в момент компиляции программы, а переменная заданная с помощью `final` получает значение в момент запуска программы. Т.е. простыми словами, значение константы `final` можно высчитать в момент запуска программы, например, с помощью присвоения переменной результата вызова функции. А вот значение константы определенной с помощью `const` должно быть известно на момент запуска программы (т.е. к моменты компиляции уже имеет значение), и следовательно, динамически определять значение в таком случае не получится.
