
## Основы List
Для создания списка (массива), используются квадратные скобки:
```
final students = ['Egor', 'Liza', 'Anna', 'Antonina'];
```

Если мы помещаем в список данные одного типа, то этот список понимает, что содержит данные одного типа и это является правильным подходом.

![[Pasted image 20250726183828.png]]

Мы конечно можем добавлять данные разных типов, но тогда массив будет отображать то, что является массивом объектов:

![[Pasted image 20250726184022.png]]

Лучше не использовать такой подход. Чтобы строго типизировать данные, содержащиеся в массиве, мы можем явно указать их тип данных в треугольных скобках перед объявлением самого массива:
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];
```

## Методы List

- `add()` - добавляет элемент в список
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];
students.add('Nikita');
print(students); //[Egor, Liza, Anna, Antonina, Nikita]
```
- `remove()` - убирает элемент из списка по значению элемента
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];
students.remove('Antonina');
print(students); //[Egor, Liza, Anna]
```
*Также у списков есть методы `removeLast()` и `removeFirst()`, удаляющие последний и первый элемент списка соответственно* 
- `removeAt()` - убирает элемент из списка по индексу элемента
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];
students.removeAt(3);
print(students); //[Egor, Liza, Anna]
```
- `addAll()` - присоединяет к массиву другой массив, при этом изменяя первоначальный массив
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];
List<String> teachers = ['Arkadiy', 'Svetofora', 'Jibrailla'];
students.addAll(teachers);

print(students); // [Egor, Liza, Anna, Antonina, Arkadiy, Svetofora, Jibrailla]
```
- `contains()` - проверяет наличие в списке конкретного элемента
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];
print(students.contains('Egor')); // true
```
- `clear()` - очищает содержимое массива
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];
students.clear();
print(students); // []
```
- `indexOf()` - возвращает либо индекс элемента, либо `-1` в случае, если ничего не найдено
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];
print(students.indexOf('Liza')); // 1
print(students.indexOf('Jojo')); // -1
```
- `where()` - возвращает список элементов удовлетворяющий условию callback функции, передаваемой в качестве параметра (callback функция принимает в себя каждый элемент и в случае если возвращает true, то добавляет его в результирующий массив, т.е. в результат вызова метода `where()`) (аналог `filter()` в JavaScript)
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];
final filteredArray = students.where(
  (element) => students.indexOf(element) % 2 != 0,
);
print(filteredArray); // (Liza, Antonina)
```
*Важно отметить, что метод `where()` возвращает не список/массив, а объект `iterable` от которого наследуются списки. Это структура данных не содержит методов доступных для списков/массивов и по факту является итерируемым объектом. Чтобы преобразовать данный объект к списку и, тем самым, получить доступ к методам списков необходимо использовать метод преобразования типов данных `toList()`*
- `toList()` - преобразует итерируемый объект к списку/массиву
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];
final filteredArray = students.where(
  (element) => students.indexOf(element) % 2 != 0,
).toList();
print(filteredArray); // [Liza, Antonina]
```


Помимо методов в списках также есть стандартные свойства, как у стандартных инстансов объекта:
- `.first/.last` - возвращает первый/последний элемент массива
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];
print(students.first); // [Egor]
```
- `.length` - возвращает длину массива
```
final students = <String>['Egor', 'Liza', 'Anna', 'Antonina'];
print(students.length); // 4
```

## Итерируемый объект Set

`Set` - это итерируемый объект, который, как и список, может содержать в себе несколько элементов, но только уникальных (невозможно добавить дубликаты элементов)
Чтобы объявить Set используются фигурные скобки:
```
final schoolClasses = <String>{'11A', '11B', '11C'};
schoolClasses.add('11A');
schoolClasses.add('11A');
schoolClasses.add('11A');
schoolClasses.add('11A');
schoolClasses.add('11A');

print(schoolClasses); // {11A, 11B, 11C}
```
*У объекта `Set` также есть метод `add()` как и у массивов. На самом деле `Set` имеет большое количество методом `List`, но не имеет доступа к методам зависящим от индекса*
