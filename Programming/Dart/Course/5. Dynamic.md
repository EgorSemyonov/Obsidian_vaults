
Dart использует строгую типизацию данных, поэтому мы не можем менять тип данных для переменной после её определения:

![[Pasted image 20250726170037.png]]

Однако существует способ работы с переменным без строгой типизации. Чтобы создать такую переменную, ей необходимо присвоить тип данных `dynamic`
```
void main() {
  dynamic my_name = "Egor";
  my_name = 10;
  print(my_name); // 10
}
```

Злоупотреблять использованием типа `dynamic` не стоит, т.к. он ломает всю прелесть строгой типизации dart
