
Входной точкой в любое приложение dart является функция (метод) вида:
```
void main() {
	print("Some text")
}
```
Данный метод вызывается по умолчанию при запуске скрипта

Для запуска скрипта из консоли используем следующий синтаксис:
```
dart run <название_файла>
```

Каждая строка кода должна заканчиваться на символ `";"`
